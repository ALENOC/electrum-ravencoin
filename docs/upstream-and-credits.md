## Lineage

```text
Electrum -> Ravencoin adaptation -> Electrum-RVN-SIG fork -> ALENOC fork
```

Thomas Voegtlin and the Electrum developers created the original wallet.
The Electrum-RVN-SIG community, including kralverde, performed the Ravencoin
conversion and asset work. ALENOC maintains this fork and does not claim
authorship of the original software or official Ravencoin status.
