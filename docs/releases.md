# Releases

Documentation: [Home](../README.md) · [Docs index](README.md) ·
[Building](building.md) · [Core certification](core-certification.md)

No maintained ALENOC binary release is currently published. The maintained
version is therefore source-oriented and must not be confused with upstream
Electrum binaries or a certified Ravencoin Core release.

When a wallet release is prepared, it must include reproducible build evidence,
checksums, signatures and tests for the exact policy/client contract. Live
deployment validation remains a separate gate from Core release certification.
